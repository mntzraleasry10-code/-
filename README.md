# -
تطبيق تكسي ذكي يربط الركاب بالسائقين بسهولة وأمان. يتيح للمستخدم طلب سيارة، وتحديد موقع الانطلاق والوجهة على الخريطة، ومعرفة الأجرة المتوقعة، وتتبع السائق مباشرة، والتواصل معه، وتقييم الرحلة. يوفر التطبيق للسائقين استقبال الطلبات وإدارة الرحلات والأرباح، مع واجهة سهلة وسريعة ودعم الدفع النقدي والإلكتروني.
